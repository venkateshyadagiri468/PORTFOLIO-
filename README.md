An ultra-unique, high-performance developer portfolio built for **Venkatesh Yadagiri**, Software Engineer specializing in Python, JavaScript, TypeScript, React, Node.js, Express.js, Django REST Framework, and PostgreSQL.

---

## ✨ Features & Architecture

- **Cyber-Lux Glassmorphism Aesthetics**: Obsidian space gray theme (`#0b132b`), radial glow mesh background, and frosted glass panels (`backdrop-filter: blur(20px)`).
- **Clean Portrait Photo Card**: Glassmorphic portrait framing with subtle lighting and stack badges.
- **Interactive Bento Grid About**: Highlights engineering methodology (Research, API Architecture, Pixel-Perfect UI, Production Deployment).
- **Categorized Technical Skills Matrix**: Organized into Languages, Frontend, Backend Systems, Databases, Developer Tools/DevOps, and Core Computer Science.
- **9 Production Repositories Showcase**: Filterable project gallery with live tabs (`All`, `Full-Stack`, `AI & ML`, `Backend`, `Frontend & Web`) linking directly to GitHub repositories.
- **Work Experience & Education**: Detailed Pitchmatter (Dubai, UAE Remote) Frontend Intern role highlights and Trinity College B.Tech CSE details.
- **Interactive Glass Contact Form**: Form validation, email permission consent toggle, direct phone/email links, and submission states.
- **Mega Watermark Footer**: Responsive branding, social links, and smooth back-to-top navigation.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Tailwind CSS, Lucide Icons, Vite
- **Styling**: Vanilla CSS3 Custom Tokens, Glassmorphism, CSS Animations
- **Backend & DBs**: Node.js, Express.js, Django REST Framework, PostgreSQL

---

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/venkateshyadagiri468/PORTFOLIO.git

# Navigate to project directory
cd PORTFOLIO

# Install dependencies
npm install

# Start local development server
npm run dev
```
